Tech4Girls LMS
A Learning Management System (LMS) built for Tech4Girls students as a final project for Tech4Girls Cohort 4. This platform provides a structured and accessible environment for learners to engage with course materials and enhance their learning experience.

Project Overview
The Tech4Girls LMS is a full-stack web application designed to support digital learning. It enables users to access educational content through a clean interface while leveraging a robust backend for authentication and data management.
This project demonstrates practical implementation of frontend development, backend APIs, authentication systems, and deployment workflows.

 Features


Student-focused LMS platform

Organized course/content access
